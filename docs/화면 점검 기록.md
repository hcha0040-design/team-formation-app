### 16:24:52, 실패한 때의 화면 내용

화면 글자(`innerText`), 학번 칸의 값, 비밀번호 칸의 글자 수를 읽었다.

```
화면: 팀 편성 / 막힘: 학번 또는 비밀번호가 틀림 / 학번 / 비밀번호 / 로그인
학번 칸: ""(비어 있음)
비밀번호 칸: 4글자
```

비밀번호(`1234`)는 채워져 있는데 학번 칸이 비어 있었다. 학번과 비밀번호 칸이 입력할 때마다 따로 서버에 보내지면서 다시 그리기와 겹쳐 학번 값이 사라진 것으로 보고, 두 칸을 `st.form`으로 묶었다(커밋 `8760247`).
